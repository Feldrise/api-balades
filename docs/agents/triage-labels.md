# Labels de triage

Les skills raisonnent en cinq rôles de triage canoniques. Ce fichier associe chaque rôle au label réellement utilisé dans l'issue tracker de ce repo.

| Label dans mattpocock/skills | Label dans notre tracker | Signification                                       |
| ---------------------------- | ------------------------ | --------------------------------------------------- |
| `needs-triage`               | `needs-triage`           | Un mainteneur doit évaluer l'issue                  |
| `needs-info`                 | `needs-info`             | En attente d'informations de la part de l'auteur    |
| `ready-for-agent`            | `ready-for-agent`        | Entièrement spécifiée, prête pour un agent autonome |
| `ready-for-human`            | `ready-for-human`        | Doit être implémentée par un humain                 |
| `wontfix`                    | `wontfix`                | Ne sera pas traitée                                 |

Quand un skill mentionne un rôle (par ex. « appliquer le label de triage prêt pour un agent »), utiliser le label correspondant de ce tableau.

Modifier la colonne « Label dans notre tracker » si le vocabulaire change.
